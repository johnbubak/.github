# FOUNDING — zentrale Donation-Buttons für @johnbubak

Dieses Projekt ist die **Single Source of Truth** für alle Support-/
Spenden-Links. Es wird als GitHub-Spezial-Repo **`johnbubak/.github`**
gepusht. Die Datei `.github/FUNDING.yml` darin gilt dann als Default
für **alle** eigenen Repos ohne eigene `FUNDING.yml`
([Docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).

Lokal: `~/projects/FOUNDING` → Remote: `github.com/johnbubak/.github`
(Branch `main`, public). Der lokale Ordnername ist beliebig, entscheidend
ist nur Name + Pfad auf GitHub-Seite.

## Regeln

1. Links nur **hier** ändern. Repos referenzieren, nicht kopieren.
2. Repo-eigene `FUNDING.yml` nur bei **Abweichung** vom Default anlegen
   (sie schlägt den Default komplett, kein Merge).
3. Gültige Keys 2026: `github, patreon, open_collective, ko_fi, tidelift,
   community_bridge, liberapay, issuehunt, polar, buy_me_a_coffee,
   thanks_dev, custom` (max 4 `custom`-URLs). Verboten: `otechie`,
   `lfx_crowdfunding` (veraltet, nicht mehr dokumentiert).
4. Nach Änderung: Sponsor-Button in einem Repo ohne eigene Datei prüfen.
