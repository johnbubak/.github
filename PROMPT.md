# Prompt: Donation-Buttons in einem Projekt einsetzen

Kopieren, `[PROJEKT]` ersetzen, ausführen:

```text
Binde die zentralen Donation-Buttons aus FOUNDING
(github.com/johnbubak/.github) in [PROJEKT] ein:

1. KEINE eigene `.github/FUNDING.yml` anlegen — der zentrale Default
   in johnbubak/.github gilt automatisch. Nur bei abweichenden Links
   eine eigene Datei anlegen (überschreibt den Default komplett).
2. README-Abschnitt einfügen:

## ☕ Support this project

Built something with [PROJEKT]? Coffee appreciated ☕

| Method | Link |
|---|---|
| ⭐ GitHub Sponsors | [github.com/sponsors/johnbubak](https://github.com/sponsors/johnbubak) |
| ☕ Ko-fi | [ko-fi.com/johnbubak](https://ko-fi.com/johnbubak) |
| 💳 PayPal | [paypal.me/janBobka](https://paypal.me/janBobka) |
| 🟡 Binance Pay | [JohnBubak](https://app.binance.com/qr/dplkj8) |

3. Vorhandene abweichende/harte Links auf diese vier URLs prüfen und
   durch die Referenz ersetzen.
4. Verifizieren: kein `FUNDING.yml` im Repo (außer bei Abweichung),
   README-Links exakt wie oben, kein otechie/lfx_crowdfunding.
```
